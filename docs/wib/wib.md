# General instructions to run the emulators a bridge

Previous to run the emulators or bridge, make the set up running:

source setup.sh

To run the wib emulators go to emulator directory and run: 

python wib_emulator_v3p1.py 

to run one wib. If you want to run more wibs, you can follow the README instructions from emulator directory.

to run the bridge, follow the instructions in the bridge directory.
